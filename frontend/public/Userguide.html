Platform Overview

🏠

KiwiQA is a full-stack online examination platform designed for enterprise-grade assessment management. It enables HR teams, educators, and organizations to create, deploy, proctor, and analyze candidate assessments at scale.

✨
Bulk Creation
Import high-quality MCQ exams via JSON or CSV upload in seconds.
📚
Question Bank
Maintain a categorized repository of reusable questions pullable into any new exam.
🛡️
Smart Proctoring
Real-time webcam monitoring with face detection + tab-switch tracking for maximum integrity.
📊
Deep Analytics
Per-candidate reports with category-wise performance breakdown, proctoring snapshots, and pass/fail analysis.
👥
Role-Based Access
Admin, Member, and Viewer roles with granular permission controls for your team.
✉️
Email Invitations
Send exam enrollment links directly to candidate emails with full tracking.

Create Exam

✏️

Build assessments through a guided 5-step wizard.

  • 1
    Exam Configuration
    Set the Exam Title, Subject / Topic, Number of Questions, Duration (minutes), and Passing Score (%).
  • 2
    Difficulty Selection
    Beginner · Intermediate · Advanced · Mixed — choose the target difficulty level for the assessment. (Selecting Question Bank defaults this to Mixed).
  • 3
    Proctoring Configuration
    Select Video Only, Screen Only, or Video + Screen (recommended) for exam integrity monitoring.
  • 4
    Question Source
    Choose from: 📚 Question Bank, ✏️ Manual entry, or 📤 Upload (JSON / CSV).
  • 5
    Review & Publish
    Preview all questions, edit options, or remove questions, then click "Publish Exam" to deploy.
💡
Upload large question sets in bulk using the JSON/CSV path to save time during exam creation.
Question Sources
Source How It Works
📚 Question Bank Select from your curated question bank. Filter by category and marks (defaults to Mixed difficulty for balanced selection).
✏️ Manual Write each question, 4 options, mark the correct answer, and add an optional explanation.
📤 Upload Import from a JSON or CSV file for bulk creation.

A persistent, categorized repository of questions reusable across multiple exams. Category cards show name, question count, and total marks.

Adding a Question — Steps
  • 1
    Provide a Category Name (existing or new — new categories are auto-created)
  • 2
    Enter Question Text, select Difficulty Level and Marks
  • 3
    Fill in 4 answer options and select the correct answer via radio button
  • 4
    Optionally add an Explanation, then click Save

Candidate Experience

🖥️
Enrollment Flow
  • 1
    Candidate receives an enrollment link (e.g., https://yoursite.com/#/enroll/{examId})
  • 2
    Fills out enrollment form: Full Name, Email, Phone, DOB, Gender, Address, and Profile Photo
  • 3
    Admin shares the Master OTP (displayed on Dashboard, rotates every ~30s)
  • 4
    Candidate enters OTP → receives a unique personal test link
Question Palette Color Coding
Color Meaning
🟢 Green Answered
🟠 Orange Visited but not answered
⬜ Grey Not visited
⚠️
If the candidate accumulates 3 or more violations (tab switches, face not detected), the exam is automatically terminated and the candidate is marked as ELIMINATED. This cannot be undone.

Security & Proctoring

🛡️
📹
Face Detection
face-api.js TinyFaceDetector monitors webcam in real-time
🖥️
Tab Monitoring
visibilitychange event detects tab switches or browser minimization
📸
Screenshot Capture
html2canvas captures 3 snapshots — start, midpoint, end — stored as base64
Additional Security Features
Feature Description
JWT Tokens Short-lived access tokens stored in localStorage; 401 auto-redirects to login
Device Fingerprinting Unique device UUID stored in localStorage prevents concurrent multi-device sessions
Question Randomization Seeded PRNG (Mulberry32) shuffles questions and options per-candidate — deterministic for auditing
Password Hashing Passwords hashed before storage — never stored in plaintext
Session Management Single active session enforced via session_id on the User model

FAQ

❓
Can a candidate retake an exam? ▼
Controlled by the Administrator. A new enrollment must be created for the candidate, generating a fresh unique test link.
How is grading done? ▼
All questions are MCQ. The candidate's selected option is compared against the is_correct flag — grading is fully automatic with instant results.
What happens when an exam link expires? ▼
The enrollment link becomes inactive. New candidates can no longer enroll. Candidates already in-progress can still submit. The admin can re-activate the link with a new time window.
Can I combine questions from different sources? ▼
Yes. Each exam uses one source at creation time (Manual, Bank, or Upload), but you can merge multiple exams using the Merge feature in Manage Exams.
How do I add multiple admins? ▼
Go to Settings → Team Management. Click "Add Member", assign a role (Admin / Member / Viewer), and select their specific permissions.
Is there a candidate or exam limit? ▼
No hard limit is enforced by the platform. Scalability depends on your hosting infrastructure (database size, server resources).
Can candidates see their own results? ▼
Currently, results are only visible to admins through the Results page and Candidate Report. Candidates see a submission confirmation on the test page.
What happens if the internet disconnects during an exam? ▼
The candidate's answers are tracked in state. They should reconnect and refresh the page. The timer continues server-side, and any previously saved progress persists.
How does the OTP system work? ▼
The admin dashboard displays a rotating Master OTP (changes every ~30 seconds). The admin shares this OTP verbally or via message with the candidate during enrollment — ensuring only authorized candidates can complete enrollment.
What if the candidate's camera fails? ▼
If proctoring is enabled with video, camera access is required. Check browser permissions and ensure no other application is using the camera.
